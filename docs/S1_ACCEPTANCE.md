## 已确认的实现口径

- dex 为全信任、同进程代码，不提供沙箱或强制终止保证。
- 禁用立即撤销宿主入口；进程内已尝试加载的 ID 不再重新创建实例。更新、再次启用和已加载插件的彻底删除通过重启生效。
- 旧设计中的热卸载和必须 GC 回收不是当前承诺；快照回滚、签名与故障恢复的缺口仍保留。
- lab 开发，InstaBox 在线时按需验证设备测试；不部署常驻调度。GitHub PR Check 跑构建、lint、单元测试和插件静态检查。
